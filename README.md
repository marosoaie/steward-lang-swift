# steward-lang-swift

Rules about the structure of Swift source, such as "a function that
returns `LoadResult` is `async`" or "private functions come last in their
type", written in a [Steward](https://github.com/marosoaie/swift-steward)
Dangerfile and built on [swift-syntax](https://github.com/swiftlang/swift-syntax).

Nothing is released yet.
